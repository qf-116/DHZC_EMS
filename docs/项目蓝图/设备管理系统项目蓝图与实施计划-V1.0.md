## 第一章　项目概述

### 1.1 项目背景

森兰生产基地现有数控车床、CNC 加工中心、摩擦焊机、焊接整线等设备 45 台，品牌涵盖发那科、广数、西门子、三菱、台达、Fagor 等多类主流厂家，控制系统与通讯协议差异较大。目前设备状态、运行效率、报警与产能数据依赖人工统计，管理者难以及时掌握全厂情况，故障响应与质量追溯高度依赖现场经验。

为支撑基地数字化运营，**将分散的设备数据统一采集、集中可视、可追溯、可分析**，特开展本项目建设。

### 1.2 建设目标

通过本次项目实现以下目标：

1. **一张大屏看全厂**：在管理中心或车间大屏上实时呈现 45 台设备的运行状态、关键指标与异常情况，管理人员可"一眼到底"；
2. **设备稼动率自动算**：系统按"运行时长、运行次数、产量、节拍、效率"自动统计，为排产与考核提供数据基础；
3. **异常分级告警**：设备停机、故障、参数超差等异常按等级实时推送，减少"设备坏了一天才发现"造成的损失；
4. **MES 工艺对比可追溯**：将 MES 下发的工艺参数与现场实采参数自动比对，为质量分析与责任界定提供依据；
5. **数据私有化、资产归用户**：本项目软件平台私有化部署，知识产权归乙方、甲方在合同期内享有使用权，解除数据安全与软件资产担忧。

## 第二章　需求分析

### 2.1 现状与痛点

| 类别 | 现状描述 | 主要痛点 |
|---|---|---|
| 设备构成 | 45 台，7 类以上品牌，3 类采集方式（协议/IO/PLC） | 协议异构，数据接入成本高 |
| 状态感知 | 现场巡检 + 人工报工 | 异常发现滞后，信息不集中 |
| 数据采集 | 关键参数分散在不同控制系统 | 缺少统一时序库与口径 |
| 效率统计 | 人工台账、Excel 汇总 | 数据滞后、口径不一、不可追溯 |
| 报警机制 | 现场口头/电话报修 | 缺少分级、自动通知与闭环追溯 |
| 工艺对比 | 无系统化比对手段 | 质量追溯依赖经验，争议难以界定 |
| 数据安全 | 关注数据是否出厂 | 对 SaaS 化部署有顾虑 |

### 2.2 业务需求

| 需求类别 | 业务目标 |
|---|---|
| 设备状态可见 | 一张图看到 45 台设备的运行/待机/故障/离线/通信延迟分布 |
| 关键参数可视 | 转速、进给、冷却、润滑、压力、电流、振动等按设备类型差异化展示 |
| 效率可析 | 运行时长、运行次数、产量、节拍、稼动率按日/周/月统计与对比 |
| 异常可追 | 报警事件分级、确认、关闭全程留痕，支持设备维保联动 |
| 工艺可溯 | MES 下发参数与现场实采自动比对，偏差超阈值时联动报警 |
| 数据可迁 | 标准 API 对接甲方 MES/ERP，支持业务系统数据回灌 |

### 2.3 非功能性需求

- **私有化部署**：平台软件部署在甲方内网或指定私有云，数据不出厂；
- **可靠性**：关键数据 24 小时内不丢失，系统可用率不低于 99%；
- **扩展性**：支持后续新增设备类型、扩展监测指标、扩展报警规则；
- **安全性**：按角色与数据范围控制访问，关键操作全程留痕；
- **运维性**：提供完整的部署、运维、升级文档与培训。

### 2.4 用户角色

| 角色 | 关注重点 | 主要使用场景 |
|---|---|---|
| 设备管理员 | 设备档案、采集接入、报警处理 | 后台管理页 |
| 生产管理员 | 稼动率、产能、停机原因 | 后台报表 + 监测大屏 |
| 维修人员 | 报警通知、维修派工、备件 | 移动端 / 报警中心 |
| 管理层 | 全厂总览、关键指标、异常中心 | 监测大屏 + 总览报表 |

## 第三章　整体设计

### 3.1 总体架构

本系统按"端—边—管—用"四层架构组织：

| 层级 | 主要能力 | 关键组成 |
|---|---|---|
| 设备层 | 现场设备与控制系统 | 数控系统、PLC、传感器、三色灯 |
| 采集层 | 协议适配与边缘计算 | 全协议采集网关、IO 采集模块、PLC 数据桥接器 |
| 平台层 | 数据汇聚、治理与服务 | 工业数据中台、设备数采平台、消息总线、时序存储 |
| 应用层 | 业务展现与交互 | 运营后台、监测大屏、报警中心、对外 API |

> 硬件归属说明：上述四层中的"采集层"硬件（采集网关、IO 模块、PLC 桥接器、传感器及配套线缆）由甲方按选配方式采购或委托第三方施工；本项目**软件服务范围不包含**硬件采购、施工与 PLC 改造。

### 3.2 部署模式

- **私有化部署**：工业数据中台与设备数采平台均部署在甲方内网服务器或私有云；
- **采集层边缘部署**：全协议采集网关部署在车间设备附近的弱电柜，按设备群划分；
- **数据流**：设备 → 采集网关 → 平台（消息队列 + 时序库）→ 应用（后台 / 大屏 / API）；
- **访问控制**：通过统一权限中心管理菜单、数据范围、按钮级操作权限。

### 3.3 数据治理原则

- **唯一来源**：所有设备数据以本平台为唯一汇总口径；
- **质量码标识**：每条数据带源时间、接收时间、质量状态，区分"无值/无效/离线/正常"；
- **可追溯**：关键数据变更、报警处理、配置调整均留审计日志；
- **可回放**：报警与统计结果可基于事件回放与重算。

## 第四章　产品流程

项目主业务流程分为五步：

```text
[设备接入]   →  数据采集  →  数据汇聚与治理  →  指标与报警  →  展现与追溯
 现场勘查       协议/IO/PLC    标准化、单位换算    规则引擎、阈值      大屏、后台、API
 点位配置       断线重连     去重、补传、死信    持续/恢复/抑制      下钻、导出、报表
```

每一环节均设置里程碑与对应交付物，确保实施过程可追踪、可验收。详细计划见第九、十章。

## 第七章　硬件数据采集指标

### 7.1 设备采集分组（45 台）

按设备类型与控制系统的可采集方式，将 45 台设备划分为三组：

| 采集组 | 设备类型 | 数量 | 控制系统/品牌 | 采集方式 |
|---|---|---|---|---|
| 协议采集 | CNC 加工中心、数控车床、摩擦焊机 | 35 | 发那科 M80（25）、三菱 M70、台达 LNC、西门子 828D（6）、西门子 M20、DD-800M4 | 工业协议直连 |
| IO 采集 | CNC 加工中心（少量） | 5 | 广数 25iMD、GUNT 350iMa、FANUC Mate-MD、西门子 802DSL、Fagor | 仅可获取开关量/运行信号 |
| PLC 数据 | 焊接/清洗/堆焊 | 5 | 焊接机 PLC、CMT 堆焊、激光焊、清洗机 | 通过 PLC 协议或厂家授权接口 |

> 重要约束：5 台 IO 采集设备和 5 台 PLC 设备的可采集指标以现场实际可达为准，部分设备**仅能获取运行/停机/报警等开关量信号**，加工参数可能无法采集。

### 7.2 采集指标矩阵

按"业务价值 × 可达性"将采集指标分为 A/B/C 三级，便于在实施过程中分级管理：

| 指标分类 | A 级（必采） | B 级（可选） | C 级（视条件） |
|---|---|---|---|
| 设备状态 | 运行/停机/故障/离线/通信延迟 | 待机/急停/手自动模式 | — |
| 加工参数 | 主轴转速、进给率、冷却液温度/压力、润滑油压 | 主轴负载、振动、电流、功率、刀具补偿 | 工艺特定参数（依厂家授权） |
| 效率参数 | 运行时长、运行次数、停机时长、节拍 | 产量、合格率、OEE 衍生指标 | 班次/工时统计 |
| MES 工艺对比 | — | 工艺下发参数（接收） | 与实采参数自动比对与超差报警 |
| 稼动率 | 整体稼动率（按日/周/月） | 设备级稼动率、班组级稼动率 | 跨车间对比 |

> 实施原则：A 级指标为项目交付必须项；B 级指标视设备能力与项目预算协商确定；C 级指标需在厂家授权或现场条件具备时方能采集。

### 7.3 采集风险提示

- **5 台 IO 采集设备**（广数 25iMD / GUNT 350iMa / FANUC Mate-MD / 西门子 802DSL / Fagor）协议封闭或部分封闭，**加工参数不可采**，仅可采集运行/停机/报警等基础信号；如甲方希望获取更多参数，需由甲方协调厂家开放协议或提供付费授权。
- **5 台 PLC 焊接/清洗/堆焊设备**需厂家提供 PLC 协议授权或开发支持，**采集可行性依赖厂家配合**；如厂家不配合，相关设备可降级为"基础状态采集"或暂不纳入。
- **西门子和 Fagor 部分机型**协议授权可能产生额外费用，由甲乙双方根据实际情况协商。

> 双方约定：以上情形下，乙方将基于现场实际可达性**协商确定采集范围**，并以**书面变更方式**确认调整范围与计划。

## 第八章　大屏展示

### 8.1 大屏定位

监测大屏是项目的"展示窗口"，部署在管理中心或车间显著位置，呈现全厂设备运行态势，支持 7×24 常驻、自动刷新与全屏展示。

### 8.2 核心展示内容

| 区域 | 展示内容 |
|---|---|
| 总览指标 | 设备总数、运行数、待机数、故障数、离线数、报警数、当日稼动率 |
| 设备分布 | 按车间/产线/状态分色排列的设备清单，支持点击下钻 |
| 异常中心 | 紧急报警、故障设备、超期任务等异常集中提示 |
| 下钻追溯 | 点击设备进入详情页，查看当前状态、关键参数、24 小时趋势与历史数据 |
| 状态颜色 | 运行（绿）/待机（蓝）/故障（红）/离线（灰）/异常（橙）等语义化色标 |

### 8.3 配套说明

大屏展示数据基于**演示快照**与**实际采集数据**双轨呈现：项目交付初期以演示数据辅助效果展示；接入实际数据后切换为实时呈现，**演示数据与实时数据不混显**。

## 第十一章　项目关键价值回顾

> 这一章是对前文的总结，方便客户业务人员快速记忆。

1. **一张大屏看全厂 45 台设备**——总览指标 + 异常中心 + 下钻追溯，进车间不用再问"现在哪台在跑、哪台停了"；
2. **设备稼动率自动算**——"运行时长/次数/产量/节拍/效率"按日/周/月自动统计，告别 Excel 汇总；
3. **MES 工艺对比可追溯**——下发参数与现场实采自动比对，质量争议有据可依；
4. **异常分级告警**——停机/故障/参数超差按等级实时推送，减少隐性损失；
5. **私有化部署、数据不出厂**——平台部署在甲方内网，知识产权归乙方、甲方有使用权；
6. **18 个月免费维保 + 后续 8800 元/年**——用得起、养得起；
7. **全协议适配覆盖 45 台异构设备**——发那科/广数/西门子/三菱/Fagor 等一个平台管；
8. **培训包含**——管理员、操作员、维修员分批上手；
9. **分期付款与里程碑绑定**——40%/55%/5% 与初验、终验挂钩，资金风险与交付对齐。
